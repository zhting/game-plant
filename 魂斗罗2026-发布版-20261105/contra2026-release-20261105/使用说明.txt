魂斗罗2026 · 当前发布版
打包日期：2026-11-05

【启动】
1. 完整解压压缩包。
2. 电脑需已安装 Node.js 22 或更新版本。
3. Windows 双击“启动游戏.cmd”，浏览器会自动打开游戏。
   也可在此目录执行：node server.mjs
4. 打开 http://localhost:3187/games/contra2026/
   游戏期间保持启动窗口运行，按 Ctrl+C 关闭服务。
   包内已包含联机依赖，无需运行 npm install。
   不要直接双击游戏 HTML；模块及素材需要通过 HTTP 服务加载。

【本包内容】
当前工作区发布配置开放主线第一至第八关，含图片、音乐、共用引擎、
原有双人联机服务和所需 ws 依赖。游戏运行文件按原样复制。
附带的 server.mjs 和启动脚本用于独立运行。

【操作】
WASD / 方向键：移动与瞄准；J：射击；K：跳跃；I：手雷；
L：使用道具；Q：切换道具；Enter / Esc：暂停。支持触屏及手柄。

【双人联机】
两台设备访问同一服务，进入“2P 联网同屏”，创建或加入六位房间码。
局域网内，其他设备将 localhost 换成运行服务的电脑的局域网 IP。
外网联机需要自行部署服务并配置域名/网络；本包不会自动开放公网。
如默认 3187 端口被占用，可设置 PORT 后再运行 node server.mjs。

【校验与部署】
release-manifest.json 包含每个原始运行文件的 SHA-256 校验值。
静态部署需保留 games/ 目录层级和 backend-config.js；双人联机需同时
运行 WebSocket 后台。附带服务使用同源 /games/contra2026/ws，
直接部署原 backend-config.js 时则保留原网站的生产后台配置。
第三方 ws 的许可证位于 node_modules/ws/LICENSE。
