魂斗罗2026 与 孙悟空（大闹天宫）源码包
打包日期：2026-11-05
来源：当前工作区文件，包括当前尚未提交的源码。

【内容】
games/contra2026/：魂斗罗源码、图片音乐、素材处理工具、设计文档。
games/wukong/：大闹天宫源码、图片音乐、素材处理工具及工具引用的原始素材、设计文档。
games/shared/：两款游戏共用的引擎和样式。
backend/：原始统一联机后台、部署文件和回归测试。
package.json / package-lock.json：原始 Node.js 依赖和锁文件。
另包含原统一后台导入的军棋与干瞪眼服务模块，以保证后台能够直接启动。

【运行】
安装 Node.js 22 或更新版本，在完整解压后的本目录执行：
  npm ci
  npm start
浏览器分别访问：
  http://localhost:3000/games/contra2026/
  http://localhost:3000/games/wukong/
如 3000 端口已被占用，请先设置 PORT 为其他端口。
两个游戏使用各自的联机房间路径；局域网其他设备可使用服务器电脑的 IP 访问。

【相关入口与联机检查】
  node --test backend/test/contra-entry.test.mjs backend/test/contra.test.mjs backend/test/wukong-release.test.mjs
本包专门收录这两款游戏，原始 npm test 脚本还引用其他游戏的测试目录；

【范围说明】
源码与资源按原样复制，保留原目录结构。当前关卡开放范围以两款游戏各自的
js/release-stages.mjs 为准。两款游戏的 README 中保留了历史制作记录。
设计目录保留文本、JSON、HTML 及 SVG 文档；大型实机截图、录屏和 QA 渲染未收录。
所有 assets 资源和 tools 素材制作脚本均已收录；部分旧工具依赖原机外部素材、
Python 包、FFmpeg 或语音模型，使用前可查看对应脚本和制作记录。
未包含 node_modules、Git 历史、本机缓存、玩家存档和真实 .env 配置；依赖通过 npm ci 安装。
source-manifest.json 记录每个原始文件的 SHA-256，便于校验。
