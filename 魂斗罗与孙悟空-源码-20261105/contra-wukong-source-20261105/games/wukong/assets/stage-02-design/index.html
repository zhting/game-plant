关底 / 青锋巨剑

增长天王

看清剑锋，躲过重劈，再把整套棍法打出去。
大招后至少留出 3 秒反击；破镇甲力阵后延长至 4 秒。

    整关节奏

    登桥见门，分路拆阵，破门决战。

    1. 01 / 登云桥学会借力

      安全试打一次机关弹，再接近守门枪阵。

    2. 02 / 天门前庭自己选路

      三座阵眼一眼可见，补给与检查点设在中央。

    3. 03 / 三条支路换三种打法

      夺弩、回雷、放锤；每破一阵，城防随之减弱。

    4. 04 / 天王台用连招收尾

      击开城门，利用破阵成果迎战青锋巨剑。

    制作安排

    先通路线，再做兵器与首领。

    1. A / 房间灰盒路要走得通

      前庭、三支路、主门与天王台；完成三选二和返程近路。

    2. B / 攻城机制棍身碰到才算

      接入实际回雷、巨弩拨杆、双锁悬锤与检查点。

    3. C / 天王战每次重劈留反击

      三招、两阶段，阵眼成果改变首领能力和反击时间。

    4. D / 画面与联机完整制作后接关

      加入正式场景、首领动画、音乐与双人同步，再接首关出口。
