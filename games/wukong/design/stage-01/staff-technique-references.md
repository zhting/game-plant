# 悟空棍法参考与游戏编排

日期：2026-10-23。

参考来源：

- [国际武联《武术套路竞赛规则与裁判法》](https://www.iwuf.org/wp-content/uploads/2023/04/TAOLU-RULES-EN-CN-1.pdf)：棍术主要技法包括平抡棍、劈棍、云棍、崩棍、绞棍、戳棍、立舞花、双手提撩花。本次根据官方检索摘要中的分类取材；该旧版 PDF 直连在查询时超时。
- [国际武联网上武术课堂课程目录](https://www.iwuf.org/xhimg/soft/240821/16-240R1091447.pdf)：含 Gunshu / 棍术完整动作与分段教学课程。目录列有基础棍术完整演示链接，但本次未成功播放其视频，没有据此声称逐帧复刻动作。

这里的十四招是根据上述技法类别为孙悟空编排的侧视游戏动作，名称和连招次序属于游戏设计。握把、重心与棍身路径由代码关键姿势定义，非视频动捕，也不作为武术教学示范。

| 游戏动作 | 主要动作区别 |
| --- | --- |
| 转腰平抡、反身回扫 | 肩腰带动横向抡击，换握后反向回扫 |
| 弓步滑把戳棍 | 手沿棍滑动，弓步前送，随后收棍 |
| 提撩挑棍、提撩回环 | 从低处撩起，接上挑或回环 |
| 双手过顶劈、左右挂劈 | 双手举过头顶，下劈或左右交替劈击 |
| 左右立舞花、双手提撩花 | 两侧翻转、握点交换与前后遮挡 |
| 仆步扫棍 | 沉身低扫，前腿伸出，身体降低 |
| 转身大抡、背身舞花 | 完整大回环，棍身阶段性位于身后 |
| 绞棍连点 | 小幅回环后连续前点 |
| 头顶云棍 | 水平面盘旋，侧视投影缩短，辅助手护身，再接平扫 |

画面中的棍头与棍尾、持棍手和近战命中共用一条几何线。多次接触同一敌人仍按原规则每招扣血一次，墙体从握点向各端分别判定阻挡。地图、角色移动规则和关卡布局沿用现有项目。
