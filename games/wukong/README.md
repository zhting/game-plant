入口：`/games/wukong/`（兼容 `/wukong`）。本机预览：http://127.0.0.1:4173/games/wukong/ 。

独立西游动作游戏：挥舞金箍棒、施展仙术与七十二变，闯过云海天宫并迎战巨灵神。当前开放第一章，支持单人和双人联网、键盘、触屏及手柄。

## 操作与招式

- WASD / 方向键移动，K / 空格二段跳。
- 短按 J 近战金箍棒：方向组合指定招式，不按方向则保留十七种基础棍招加三套完整连段的随机选择。连续点按衔接普通三连击，可在收招前约 0.4 秒预输入下一招；当次输入的方向与朝向保留，松开或转身不会把下一招换掉。整身画稿呈现转腰蓄力、弓步送棍、翻腕换侧、举棍过顶和低扫收势。随机候选尽量遍历全部招式，并避开最近两类相似画面；候选队列、搓招窗口及预输入随主机快照同步。棍头、棍尾沿可见棍身接触才命中，各招每一击对同一目标只扣一次血，实心墙体分别挡住两端。

| 组合（WASD 与方向键等效，X 可代替 J） | 招式 |
| --- | --- |
| ← / → + J | 弓步直捣，向指定方向突刺 |
| ↑ + J | 挑棍撩天 |
| ↓ + J | 伏身扫堂，使用完整低扫姿势；单独↓仍是伏地 |
| ↖ / ↗ + J | 绕顶花棍 |
| ↙ / ↘ + J | 横扫千军，横扫→上挑→追击三段 |
| ↓，在约 0.3 秒内转← / → + J | 莲花回环，舞花→反花→下劈三段，可经过斜下方向 |
| 空中 ← / → + J | 凌空直刺 |
| 空中 ↑ + J | 腾空挑棍 |

触屏摇杆 + 棍击、手柄方向 + X / RT 共用以上规则；空中不按方向短按 J 保留四种随机招式。当前定向棍招名称显示在气血/怒气栏下方。方向组合会完整播放各自的起手、发力和收势；持续按住攻击时，出招能量一并积累，但须播完组合棍招才进入蓄力姿势，不再被 0.24 秒的蓄力切掉。动作期间锁定所用走动/站立序列，放开方向键不再中途换姿势。方向组合不改变原地图与行走物理；仙术分身和小猴仍自行选择近战招式。
- 空中按 S / 下方向键：无需攻击键就发动举棍下劈，约 0.11 秒蓄势后向下劈落，落地播放棍头触地冲击和收招。每次腾空自动触发一次，命中 4 点并产生重击反馈。完整劈棍帧在空中先完成向下砍击，再保持低位收势直到着地；落地时棍身按平台表面遮挡。
- 长按 J（或屏幕棍击按钮、手柄 X / RT）后松开：无方向输入时 0.24 秒起进入聚气；组合棍招先播完再进入聚气，约 0.55 秒可发普通棍气，1.25 秒蓄满。普通/满蓄分别造成 4/7 点伤害，可穿透 3/5 个目标，射程 235/350 游戏单位。金色月牙气刃与蓄力条直接使用 Canvas 绘制，配合聚气、可释放、满蓄与发射音效，无新增图片下载。棍气走独立轨迹与扫掠碰撞，先击中墙前目标，遇实心墙体消散；受击、死亡、大招、暂停和进入出口会中断蓄力，松开不会误发。可边移动、跳跃、骑麒麟或驾云蓄力；召唤物继续自动近战。疾风/疾速加快充能，长棍增加气刃大小与射程，三棍发射三道，烈焰追加伤害。
